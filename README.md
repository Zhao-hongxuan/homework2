## Описание задач

### Задача 1: Функция проверки палиндрома  
**Файл**: `2_1.py`  
- Реализовать функцию `is_palindrome(s)`, определяющую, является ли заданная строка палиндромом  
- Игнорировать регистр и не-буквенно-цифровые символы  
- Включить несколько тестовых примеров  

### Задача 2: Функция фильтрации строк  
**Файл**: `2_2.py`  
- Реализовать универсальную функцию фильтрации `filter_strings(filter_func, string_array)`  
- Использовать лямбда-функции для трёх правил фильтрации:  
  - Исключить строки, содержащие пробелы  
  - Исключить строки, начинающиеся с буквы "a"  
  - Исключить строки длиной менее 5 символов  

### Задача 3: Иерархия классов графических фигур  
**Файл**: `2_3.py`  
- Создать базовый класс `Graphic`  
- Реализовать четыре подкласса: `Square`, `Rectangle`, `Triangle`, `Circle`  
- Каждый класс должен реализовывать методы вычисления площади, периметра и сравнения  

### Задача 4: Классы Студент и Аспирант  
**Файл**: `2_4.py`  
- Создать класс `Student` и подкласс `GraduateStudent`  
- Реализовать методы отображения информации, вычисления стипендии и сравнения стипендий  
- Рассчитывать размер стипендии на основе среднего балла  

### Задача 5: Декоратор времени выполнения  
**Файл**: `2_5.py`  
- Реализовать декоратор `timing_decorator` для измерения времени выполнения функции  
- Протестировать две функции:  
  - Вычисление суммы двух чисел с выводом в консоль  
  - Чтение двух чисел из файла, вычисление результата и запись в файл  
- Включить тестовые файлы `input.txt` и `output.txt`
